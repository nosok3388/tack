напиши функцию Divide(a, b float64) (float64, error). Она должна:

Возвращать результат деления, если b != 0.
Возвращать ошибку, если b == 0 (используй errors.New).
В main вызови функцию с разными значениями и корректно обработай ошибку через if err != nil.


Пакет: errors — errors.New("message").
Идиомы ошибок в Go: возврат (result, error), проверка if err != nil.
Не используй исключения/panic для нормальной логики.
